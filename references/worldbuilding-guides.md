## How to use these notes

- Read the relevant extraction before choosing a bake setting, asset source or prefab. Source URLs and access/version caveats belong with each topic.
- Historical Unity/VRChat observations are diagnostic leads, not guarantees for Unity 2022.3 or the current SDK. Verify installed package APIs before scripting them.
- Existing workspace/project constraints still apply: no unsolicited stations or prop colliders, reflection probes after every lighting bake, and independent visual review of scene changes.
- Download availability is not a license. Verify original authorship, allowed use and attribution for each asset; a porter cannot grant rights to a game's underlying assets. Private use does not establish permission.
- No project assets, package dependencies, scenes or lighting settings are changed by this reference review.
