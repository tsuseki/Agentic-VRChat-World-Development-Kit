**When:** Setting up or debugging VRC Light Volumes (`red.sim.lightvolumes`) with Bakery.
**Version scope:** the 3.0.1 rules were verified on a Bakery 1.98 world in 2026-10 (31 volumes, full render, sphere test). The 2.x rules below are kept for worlds still on 2.x; 2.x → 3.x drops the authoring components and old shadowmasks and is not easily reversible, so back up the scene and check dependent packages (LTCGI, GLIM, lilToon, VizVid) against the new `LightVolumes.cginc`.
**Rules (3.0.1):**
- Only LV-aware shaders read volumes: avatars on lilToon/Poiyomi, the package's `Light Volume Samples/Light Volume PBR` and the compatible-shader list. Standard props and pickups stay probe-lit; lightmapped surfaces only receive Additive volumes.
- A full Bakery `Render` (Manager Baking Mode = Bakery) is the only path that bakes volumes; LV hooks `OnPreFullRender`/`OnFinishedFullRender`, imports the textures and packs the atlas itself (log `[LightVolumes] Bakery bake complete. Atlas packing queued.`). Probe-only and selected-group renders import nothing.
- Each volume needs a hidden direct child `Bakery Volume - <name>`. It is created only by Inspector edits or onboarding, never when the mode is set by script, and a volume without it is silently skipped (open issue #113). After scripting `BakingMode = 1`, call `LightVolumeTools.SetupBakeryDependencies(volume, true)` per volume and check exactly one helper child each (`BakeryVolume` lives in `BakeryRuntimeAssembly`).
- Create volumes with `UdonSharpUndo.AddComponent<LightVolumeInstance>`, then `ApplyRuntimeState` and onboarding (or the `GameObject/Light Volume` menu); a proxy without its UdonBehaviour blocks the SDK build.
- ≤32 active regular+additive volumes (highest weights win beyond that); only active volumes bake, so keep far islands active during the render. Unique GameObject names per volume. Overlap neighbours by the 0.25 m blend; at most two volumes blend per pixel. Keep Light Probes Blending on so pixels outside every volume use probes instead of the lowest-weight volume's clamped edge.
- Fix Light Probes L1 (default on) rewrites the scene's baked probes after every full render (L1 ×0.5 + clamp, not idempotent): it changes every probe-lit object, so turn it off when the probe look must stay. Force Scene Lighting is a global int that removes lilToon/Poiyomi brightness limits world-wide, including the dark garden.
- LV disables Bakery Compress volumes and forces a geometry re-export before the render (#95 auto-fix), and Auto shader stripping rewrites `Packages/red.sim.lightvolumes/Shaders/LightVolumesBuildConfig.cginc` (commit it). LV adds the `VRC_LIGHT_VOLUMES` define and never removes it; VizVid 1.8.2 failed to compile (`PointLightVolume` not found) until that define was present for Standalone.
**Rules (2.x):**
- Keep Bakery **Compress volumes** off (`renderSettingsCompressVolumes = false` on both `ftLightmapsStorage` and `ftGlobalStorage`): BC7 volume textures are rejected at pack time.
- `LightVolumeSetup` hooks `OnFinishedFullRender`; a probe-only render does NOT fire it, so invoke `FixLightProbes` (private static) + `SyncUdonScript` manually. Resolution is owned by the `LightVolume` component; editing the BakeryVolume gets overwritten.
- Run exactly one `GenerateAtlas()` + `SyncUdonScript` afterwards, never concurrent with the auto-repack: overlapping runs corrupt the atlas (objects blow out white).
**Both versions:**
- Voxels inside bedding/floors bake near-black without being flagged invalid; higher density makes it worse. Fix that worked on 2.x: per-column "darkness clamp" walking down from below the ceiling, replacing voxels with L < 0.45× the voxel above, applied to all three textures.
- With a lightmapped Standard interior, check first whether volumes add anything; removing them can expose probe defects they were masking.
**Verify:** in play mode (edit mode pushes no volume globals), place an LV-PBR sphere and a Standard reference sphere at each player pose and capture with the Manager GameObject active vs inactive (`_UdonLightVolumeEnabled` 1 → 0). Healthy result: LV/probe luminance ratio around 0.8–1.6, no black or blue-sided spheres, no steps along a sphere row crossing volume boundaries.
